# Quest 3 WebXR Vision Trainer / 視力トレーニング

Meta Quest 3向けのWebXR視力トレーニング＆水中リラクゼーションアプリです。  
**MR（カラーパススルー）**、**VR（没入空間）**、および **PCブラウザ上の3Dプレビュー** に対応し、コントローラー・ハンドトラッキング（ピンチ）・視線（Gaze）操作のすべてで動作します。

## 機能・トレーニングモード

1. **遠近調節・ストレッチ** (`FocusStretchMode`)
   - `0.38m〜12.0m` の遠近往復・3D 8の字軌道・螺旋追従の3パターンで毛様体筋をほぐします。
   - 呼吸ガイドリングとターゲット内記号（`▲ ● ★ ◆`）のピント判定を搭載。
2. **動体視力・周辺視野** (`PeripheralMode`)
   - 中央の十字を意識しながら、周辺視野（最大58°）に立体音響とともに出現・移動するターゲットを捉え、反応速度（ms）を計測します。
3. **3Dガボールパッチ** (`GaborPatchMode`)
   - GLSLカスタムシェーダーで数式生成した高精細ガボールパッチから、見本と同じ角度・空間周波数のパッチを探索します。レベルに応じて角度差とコントラストが自動調整されます。
4. **両眼視・立体視** (`BinocularMode`)
   - WebXRの左右カメラレイヤー分離（`Layer 1` / `Layer 2`）を用いた**両眼融像（Fusion）**と、4つのリングから手前に浮き出て見える1つを当てる**微細立体視奥行き判定（Stereopsis）**を搭載しています。
5. **水中リラクゼーション** (`AquaticRelaxMode`)
   - プロシージャル生成された10種の水棲生物・水草（熱帯魚、錦鯉、ウミガメ、マンタ、クラゲ、タツノオトシゴ、イカ、バリスネリア、有茎草、サンゴ等）と上昇する気泡・水中コースティクスに囲まれ、10秒周期の深呼吸と遠方注視で目の緊張を和らげます。

## 操作方法

- **VRコントローラー**: レーザーポインターを合わせてトリガーで決定（左スティックで水平移動、右スティックで高さ調整・旋回）
- **ハンドトラッキング**: レーザー／ポインターを合わせてピンチ操作で決定（空間内の `視点 +高 / -高 / 前へ / 後へ` ボタンで位置調整可能）
- **視線（Gaze）操作**: レティクル（中央カーソル）をボタンやターゲットに一定時間合わせ続けると自動決定（メニューからON/OFF切替可能）
- **PCブラウザ（Desktop 3D Preview）**: 左クリックで選択、ドラッグで視点回転、`WASD`/矢印キー・マウスホイールで位置移動、`Q`/`E`（または`Space`/`C`）で高さ調整、`R` キーで視点リセット

## 技術スタック

- **TypeScript + Vite + Three.js**
- **`@vitejs/plugin-basic-ssl`**（Quest 3実機LAN接続用のローカルHTTPSサーバー）
- **Web Audio API**（3D定位ピン音・呼吸ガイド・癒やし音生成）
- **`localStorage`**（モード別のハイスコア・精度・累計時間の保存）

## セットアップ・起動

```powershell
# 依存パッケージのインストール
npm install

# HTTPS開発サーバーの起動（PC・Quest 3両対応）
npm run dev
```

### Meta Quest 3 実機からの接続
1. PCとMeta Quest 3を同じWi-Fiネットワークに接続します。
2. `npm run dev` 実行時に表示される Network URL（例: `https://192.168.x.x:5173/`）をQuestブラウザで開きます。
3. 自己署名証明書の警告が表示された場合は「詳細設定」→「進む」で許可し、**「Enter MR (Passthrough)」** または **「Enter VR (Space)」** を選択してください。

## ビルド・Cloudflare Workersへのデプロイ

```powershell
# TypeScript型チェック + プロダクションビルド
npm run build

# Cloudflare Workersへデプロイ（cf CLI使用）
cf deploy
# または型チェック付きデプロイ
npm run deploy
```

デプロイ設定は [cloudflare.config.ts](./cloudflare.config.ts) に定義されています。
